# ChakraSutra

ChakraSutra is a wellness-first yoga web app concept focused on safe practice, personalized guidance, mood-aware routines, weather-informed suggestions, and live posture feedback.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local static server.

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — app layout
- `styles.css` — modern wellness styling
- `app.js` — interactivity, mood logic, recommendations, live pose simulation

## Notes

This is a front-end prototype inspired by the ChakraSutra concept. It includes:
- onboarding profile form
- wellness and safety plan generation
- mood-based recommendation cards
- live pose feedback simulation with red/yellow/green cues
- hydration and meal tips
- language-coaching variations

The app name is intentionally `ChakraSutra` and not `ChakraSutra AI`.
